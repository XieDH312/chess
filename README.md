# NOVA Chess

This public repository distributes NOVA Chess release packages only.

Download the latest Windows, Android ARM64 and Web packages from Releases.

- Windows: extract the entire ZIP into a new directory and run `chess.exe`.
- Android: install the APK using Android's system installation screen.
- Web: extract and serve the directory using an HTTP/HTTPS static server.

SHA-256 checksums are provided in `checksums-sha256.txt`. Native app versions
from 1.0.1 check this repository for updates and verify downloaded packages.

Stockfish 18 and its GPL v3 notices are included in the platform packages.
Corresponding upstream source: https://github.com/official-stockfish/Stockfish/releases/tag/sf_18
